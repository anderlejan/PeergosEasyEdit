A simple text editor as a [Peergos](https://peergos.org) custom app, for the text files in your Peergos drive. This is the first public release.

**Saving you can trust:** "Saved ✓" appears only after Peergos accepted the file and reading it back gave exactly the bytes that were sent. Every failure stays on screen with **Try again** and **Save as…**. Earlier versions could lose text without a message when Peergos had been idle for a while; this version repeats such a save and checks it.

- **Autosave** after 2, 5 (default), 10 or 30 seconds without typing, or off; at least every 30 seconds while you keep typing, and when you switch to another window.
- **Nothing lost when something fails:** while text is not saved, a copy is kept in this browser and offered back when the file is opened again. A file that could not be read is never shown empty and cannot be saved over.
- UTF-8 text; Windows line endings and the byte order mark are kept; files in other encodings open read-only.
- **Save as…**, Ctrl+S, an "Unsaved changes" mark; themes, text size, font and line wrapping; notes with export and import.

Permissions: **edit the file chosen by the user** and **store app data** (notes and settings).

### Install
1. Download `PeergosEasyEdit-v1.1.0.zip` below.
2. In Peergos, upload it to your drive and click it to open it.
3. Open the menu (⋮) of `peergos-app.json` → **Install** → confirm. Installing over an older version keeps your notes and settings.
4. Open a text file from your drive with PeergosEasyEdit, or start it from the app launcher.

Peergos 1.38 and older cannot install from inside a ZIP: unpack it, upload the folder, then use the menu of `peergos-app.json` → **Install App**.
