Undo and redo with an edit history, renaming, interface size – and the editor comes back as you left it.

- **Undo and Redo** buttons (also Ctrl+Z, Ctrl+Y, Ctrl+Shift+Z). Typing without a pause is one step; a restored draft or "their version" after a conflict can be undone too.
- **Edit history** (Options → Side panel → Edit history): the steps of the file shown, newest first – click one to go back, or forward again. Kept only while the file is open; it is never stored, in Peergos or on the device.
- **File → Rename…** renames the file in Peergos (in the folders you granted the editor) and shows the new name at once; unsaved changes stay in the editor.
- **Interface size** (Options) for menus, buttons and windows, separate from the size of the text you edit (A− A+).
- **Back as you left it:** started from the launcher, the editor shows your tabs, the one file you had open, or – if you closed everything – the start screen with recent files.

Fixed
- Without tabs, more than one file could stay open: switching tabs off only hid the tab bar. Now it closes all but the file shown, asking about unsaved changes first.

Changed
- "Notes panel" in Options became "Side panel" (Off, Notes, Edit history); a notes panel that was on stays on.

Permissions: **edit the file chosen by the user** and **store app data** (notes, settings, drafts, open tabs and recent files). Folders for Open…, Save as… and Rename… are granted separately, when you choose **Add folders…**.

### Install
1. Download `PeergosEasyEdit-v1.3.0.zip` below.
2. In Peergos, upload it to your drive and click it to open it.
3. Open the menu (⋮) of `peergos-app.json` → **Install** → confirm. Installing over an older version keeps your notes and settings.
4. Open a text file from your drive with PeergosEasyEdit, or start it from the app launcher.

Peergos 1.38 and older cannot install from inside a ZIP: unpack it, upload the folder, then use the menu of `peergos-app.json` → **Install App**.
