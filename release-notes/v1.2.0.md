Open and save anywhere in your Peergos drive, tabs, recent files – and nothing kept on your device.

- **File menu:** New, Open…, recent files, Save (Ctrl+S), Save as…, Close. **Open…** and **Save as…** browse the folders you let the editor use (Peergos asks once and remembers them on every device), and can make new folders. Any other file can be picked with Peergos' file picker. Names with `+ & # %` work there.
- **Starts from the Peergos launcher** with the full editor: New text, Open…, recent files and unsaved texts.
- **Tabs** (Options → Tabs): the tabs you leave open come back the next time, on any device.
- **Recent files** (5, 10 or 20, or off); a file deleted or moved meanwhile is marked as not found.
- **No overwriting by surprise:** before saving, the editor checks that the file was not changed or deleted elsewhere since it was opened, and asks what to do.
- **Nothing on the device:** text not yet saved is kept as a draft in the app's own Peergos folder, encrypted like your files, instead of in the browser. Unsaved texts that 1.1.0 kept in the browser are moved there on the first start, then deleted from the browser.
- **Compact look:** an **Options** menu (theme, font, autosave, tabs, recent files, line wrapping, line numbers, notes panel, backup, help, about); optional line numbers; six more themes; **Show all** notes in one window to read or copy them.

Permissions: **edit the file chosen by the user** and **store app data** (notes, settings, drafts, open tabs and recent files). Folders for Open… and Save as… are granted separately, when you choose **Add folders…**.

### Install
1. Download `PeergosEasyEdit-v1.2.0.zip` below.
2. In Peergos, upload it to your drive and click it to open it.
3. Open the menu (⋮) of `peergos-app.json` → **Install** → confirm. Installing over an older version keeps your notes and settings.
4. Open a text file from your drive with PeergosEasyEdit, or start it from the app launcher.

Peergos 1.38 and older cannot install from inside a ZIP: unpack it, upload the folder, then use the menu of `peergos-app.json` → **Install App**.
