HTML files shown as a page, Find and Replace, and handier typing.

- **HTML files** (.html, .htm) open as a browser shows them, as Peergos' own viewer does: their styles, pictures and stylesheets from your granted folders, links to files there (they open in the editor). Their scripts are not run and nothing is loaded from other web sites. **Source** shows the HTML text to edit, **Preview** the page again.
- **Find and Replace** (Ctrl+F, Ctrl+H, also File → Find… and Replace…): next and previous (Enter, Shift+Enter, F3), match case, whole words, replace one or all – Undo takes it back. The match is marked while you type in Find.
- **Tab** types a tab and indents selected lines; **Shift+Tab** takes it back. (Escape, then Tab, leaves the text with the keyboard.)
- **Word count** in the bar – words and characters, of the selection too (Options → Word count).
- **Options → Spell check**, also in the formatted Markdown view.
- **Ctrl+B** and **Ctrl+I** in Markdown Source write bold and italic.

Changed
- **Open…** starts in the folder of the file you opened last – on every device, as recent files are kept in Peergos; **Save as…** of a new text starts there too.
- Editing a big Markdown file formatted stays smooth. A Markdown file over 400 000 characters opens as text, because the formatted view takes long to load; **Formatted** shows it anyway.

Permissions: **edit the file chosen by the user** and **store app data** (notes, settings, drafts, open tabs and recent files). Folders for Open…, Save as…, Rename…, pictures and links are granted separately, when you choose **Add folders…**. The app includes Toast UI Editor 3.2.2 and KaTeX 0.16.11 (both MIT License), unchanged.

### Install
1. Download `PeergosEasyEdit-v1.5.0.zip` below.
2. In Peergos, upload it to your drive and click it to open it.
3. Open the menu (⋮) of `peergos-app.json` → **Install** → confirm. Installing over an older version keeps your notes and settings.
4. Open a text file from your drive with PeergosEasyEdit, or start it from the app launcher.

Peergos 1.38 and older cannot install from inside a ZIP: unpack it, upload the folder, then use the menu of `peergos-app.json` → **Install App**.
