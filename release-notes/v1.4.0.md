Markdown files edited as they look, import and export, and a handier bar and side panel.

- **Markdown files** (.md) open formatted and are edited as they look – headings, lists, task lists, tables, quotes, code, links, pictures from your granted folders, math, struck out, sub- and superscript (H~2~O, X^2^), shown as Peergos' own viewer shows them. **Source** in the bar shows the exact text, and back. Editing formatted changes only the blocks you edit: the rest of the file keeps its own Markdown exactly, and formulas are kept exactly. Ctrl+click opens links; links to other files in granted folders open them in the editor.
- **Options → Formatting buttons:** bold, italic, struck out, H1–H3, lists, task list, quote, code, link, table, picture and line in the bar. Formatted they format; in Source they write the Markdown. With them on, any text file can be shown and edited formatted.
- **File → Import…** brings a UTF-8 text file from your device into Peergos (it opens with its name, then Save as…); **File → Export…** downloads the text shown to your device, under a name you choose, or copies it to the clipboard.
- **Notes** and **History** buttons in the bar switch the side panel; drag its edge to make it wider or narrower (double-click: normal width).
- The mouse wheel over A−, the text size or A+ makes the text bigger or smaller.

Changed
- Recent files are in a submenu: **File → Recent files ▸**.
- Without tabs, a × next to the file name closes the open file.
- Menus stay inside the window when the bar takes two rows.

The app now includes two libraries, unchanged: Toast UI Editor 3.2.2 and KaTeX 0.16.11 (both MIT License).

Permissions: **edit the file chosen by the user** and **store app data** (notes, settings, drafts, open tabs and recent files). Folders for Open…, Save as…, Rename…, pictures and links are granted separately, when you choose **Add folders…**.

### Install
1. Download `PeergosEasyEdit-v1.4.0.zip` below.
2. In Peergos, upload it to your drive and click it to open it.
3. Open the menu (⋮) of `peergos-app.json` → **Install** → confirm. Installing over an older version keeps your notes and settings.
4. Open a text file from your drive with PeergosEasyEdit, or start it from the app launcher.

Peergos 1.38 and older cannot install from inside a ZIP: unpack it, upload the folder, then use the menu of `peergos-app.json` → **Install App**.
