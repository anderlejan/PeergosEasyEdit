    Backup

    Copy in this browser

    While you edit, the editor keeps a copy of your text in this browser, so a save that fails, or a window closed without saving, does not lose it. The copy stays on this device only.

    Notes and settings

    Export gives your notes and settings as text you can keep. Import replaces your notes and settings with such a text.

    Help

    Opening a file

    Open a text file from your Peergos Drive with PeergosEasyEdit. Started from the launcher without a file, the editor starts empty and Save asks Peergos for a name and folder.

    Saving

    Press Save or Ctrl+S. The editor then reads the file back from Peergos and compares it with what it sent. Only then the status says Saved. If anything goes wrong, a red message stays on top until the text is saved, with Try again and Save as…. Your text is never replaced by what Peergos sends back.

    A dot before the file name and the words Unsaved changes mean the file in Peergos does not have your latest text yet.

    Autosave saves by itself a few seconds after you stop typing (choose how long, or Off), at least every 30 seconds while you keep typing, and when you switch to another window. It is checked the same way as Save. If it fails, the red message says so and autosave tries again 30 seconds later. A text started without a file is not saved automatically, because Peergos would have to ask for a name.

    Save as… saves a copy under another name; Peergos asks for the name. The editor keeps working on the file it opened.

    Text that was not saved

    The editor keeps a copy of your text in this browser while you type (see Backup). When you open the file again and that copy has changes the file does not have, the editor offers them back. It also tells you when the file is not what you last saved here, for example after it was changed on another device.

    File names

    Peergos passes the file name to apps in a way that changes the characters + & # %. The editor notices this and does not open such a file, so it cannot save to the wrong place. Rename the file in your Drive and open it again. Peergos cannot open files whose name has a % sign in any app at the moment.

    Text encoding and line endings

    Files are read and written as UTF-8. A file that is not valid UTF-8 opens read-only, so it cannot be damaged. Windows line endings (CR LF) and a UTF-8 byte order mark are kept as they were.

    Look

    A− and A+ change the text size. Under Options: theme, font, autosave, line wrapping, line numbers and the notes panel. Every choice applies and is saved at once, in Peergos, so it is the same on every device.

    Notes

    Options → Notes panel shows a panel for your own notes about anything. They are saved in the app's own folder in Peergos. Show all puts every note in one window with a tick box each, to read them together or copy the ticked ones. If the notes cannot be read, the panel says so and does not change them until they could be read.

    Backup

    Options → Backup: Export gives your notes and settings as text to keep; Import replaces your notes and settings with such a text after asking.

    History

    1.1.0 (2026-10-23)

    • Saving no longer loses text silently: when Peergos has been idle, the first save used to fail without a message. The editor now repeats such a request, reads the file back to check it, and shows every failure until the text is saved.
    • The editor never replaces your text with what Peergos sends back after saving.
    • Keeps a copy of your text in this browser and offers unsaved changes back when the file is opened again.
    • Files whose names Peergos passes on changed (+ & # %) are not opened, instead of opening empty.
    • A file that could not be read is never shown as empty and cannot be saved over.
    • Files that are not UTF-8 open read-only; Windows line endings and the byte order mark are kept.
    • Autosave (after 5 s by default; 2, 10, 30 s or off in the toolbar).
    • Save as…, Ctrl+S, an "Unsaved changes" mark; settings apply and save at once.
    • Notes that could not be read are no longer replaced by an empty list.
    • Rewritten from scratch; help and history are part of the app instead of its data folder.

    1.0.5 (2025-01-10)

    • New icon; corrected dates in the history; smaller fixes.
