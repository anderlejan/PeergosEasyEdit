      Drafts in Peergos

      Text that is not in its file yet – a new text, changes while autosave is off, or a save that failed – is kept as a draft in the app's own folder in Peergos, encrypted like your files, and offered back on any device. Nothing is kept on this device.

      Notes and settings

      Export gives your notes and settings as text you can keep. Import replaces your notes and settings with such a text.

      Help

      Opening a file

      Open a text file from your Peergos Drive with PeergosEasyEdit, or start the editor from the launcher and use File → Open…. Started from the launcher, the editor comes back as you left it, on any device: with your tabs, with the one file you had open, or – if you closed everything – with New text, Open…, your recent files and any unsaved texts kept in Peergos.

      Granted folders

      Open… and Save as… browse the folders you let the editor use. Choose + Add folders…: Peergos asks which folders. Peergos remembers them on every device until you remove them (× next to the folder, or in the app's details on the Peergos launcher). Your home folder itself cannot be granted, the folders in it can. Pick any file with Peergos' picker… opens one file without granting its folder; such a file can be edited only until the editor is closed.

      Saving

      Press Save or Ctrl+S. The editor then reads the file back from Peergos and compares it with what it sent. Only then the status says Saved. If anything goes wrong, a red message stays on top until the text is saved, with Try again and Save as…. Your text is never replaced by what Peergos sends back.

      A dot before the file name and the words Unsaved changes mean the file in Peergos does not have your latest text yet.

      Before saving, the editor checks that the file is still the one it opened. If it was changed somewhere else (another device or app), nothing is saved and you choose: Show their version, Overwrite with mine or Save mine as…. If it was deleted, moved or renamed, you can save it there again or somewhere else.

      Autosave saves by itself a few seconds after you stop typing (choose how long, or Off), at least every 30 seconds while you keep typing, and when you switch to another window. It is checked the same way as Save. If it fails, the red message says so and autosave tries again 30 seconds later. A new text is not saved automatically: it needs a name first (Save asks for one).

      Save as… saves the text into a granted folder under the name you choose, and the editor goes on with the new file. Without granted folders, Peergos' own save dialog is used and the editor keeps working on the file it opened.

      Tabs

      Without tabs, one file is open at a time: opening or starting another closes it, after asking whether to save it if it has unsaved changes. Options → Tabs lets you keep several files open, one per tab (+ starts a new text). Switching tabs off closes all but the file shown, asking about each one with unsaved changes; if you cancel, tabs stay on. Whatever is open when you leave comes back the next time the editor starts from the launcher. A file opened from the Drive comes back only if it is in a granted folder.

      Renaming

      File → Rename… renames the open file in Peergos; the new name shows at once and unsaved changes stay in the editor. Peergos lets the editor rename files only in granted folders; for a file opened from elsewhere, rename it in the Drive or grant its folder first. A new text just gets the name it will be saved under.

      Undo and redo

      ↶ and ↷ in the bar, or Ctrl+Z and Ctrl+Y (also Ctrl+Shift+Z). Typing without a pause counts as one step. A restored draft or "their version" after a conflict can be undone the same way. Options → Side panel → Edit history lists the steps of the file shown, newest first; click one to go back to it, or forward again. Undoing all the way back to what is in the file means there is nothing left to save. The history is kept only while the file is open – it is not saved anywhere.

      Recent files

      File lists the files you opened last (how many: Options → Recent files, or off). A file that was deleted or moved meanwhile is marked not found; × removes it from the list. The list is kept in Peergos, so it is the same on every device.

      Text that was not saved

      Text that is not in its file yet – a new text, changes while autosave is off, or a save that failed – is kept as a draft in the app's own folder in Peergos (see Backup). When you open the file again, the editor offers those changes back. An unsaved new text comes back in its tab, or is offered on the start screen.

      Privacy

      The editor keeps nothing on this device: no texts, no drafts, no file names, no settings – not in browser storage and not in the browser's databases. Everything it keeps is in Peergos, encrypted like your files. It makes no requests outside Peergos.

      File names

      Peergos passes the file name to apps in a way that changes the characters + & # %. The editor notices this and does not open such a file, so it cannot save to the wrong place. Rename the file in your Drive and open it again. Peergos cannot open files whose name has a % sign in any app at the moment.

      Text encoding and line endings

      Files are read and written as UTF-8. A file that is not valid UTF-8 opens read-only, so it cannot be damaged. Windows line endings (CR LF) and a UTF-8 byte order mark are kept as they were.

      Look

      A− and A+ change the size of the text you edit; Options → Interface size changes the menus, buttons and windows. Also under Options: theme, font, autosave, recent files, tabs, line wrapping, line numbers and the side panel. Every choice applies and is saved at once, in Peergos, so it is the same on every device.

      Notes

      Options → Side panel → Notes shows a panel for your own notes about anything. They are saved in the app's own folder in Peergos. Show all puts every note in one window with a tick box each, to read them together or copy the ticked ones. If the notes cannot be read, the panel says so and does not change them until they could be read.

      Backup

      Options → Backup: drafts of unsaved text can be switched off or deleted there. Export gives your notes and settings as text to keep; Import replaces your notes and settings with such a text after asking.

      History

      1.3.0 (2026-10-24)

      • Undo and Redo (also Ctrl+Z, Ctrl+Y); Options → Side panel → Edit history lists the steps of the open file, to go back to any of them. Kept only while the file is open.
      • File → Rename… renames the file in Peergos and shows the new name at once.
      • Options → Interface size for menus, buttons and windows.
      • Started from the launcher, the editor comes back as it was left: tabs, the one file, or the start screen.
      • Fixed: without tabs, more than one file could stay open.

      1.2.0 (2026-10-23)

      • File menu: New, Open…, recent files, Save, Save as…, Close. Open… and Save as… browse the folders you let the editor use, and can make new folders; any other file can be picked with Peergos' picker.
      • Starts from the launcher with the full editor. Optional tabs that come back the next time, on any device. Recent files, with files that are gone marked as not found.
      • A file changed or deleted somewhere else is never overwritten without asking.
      • Nothing is kept on the device: unsaved text is kept as a draft in Peergos, encrypted, instead of in the browser.
      • Options menu for a compact bar; line numbers; six more themes; Show all notes in one window to read or copy them.
      • Fixed: the Notes button did not hide the notes panel; a white border around the app.

      1.1.0 (2026-10-23)

      • Saving no longer loses text silently: when Peergos has been idle, the first save used to fail without a message. The editor now repeats such a request, reads the file back to check it, and shows every failure until the text is saved.
      • The editor never replaces your text with what Peergos sends back after saving.
      • Keeps a copy of your text in this browser and offers unsaved changes back when the file is opened again.
      • Files whose names Peergos passes on changed (+ & # %) are not opened, instead of opening empty.
      • A file that could not be read is never shown as empty and cannot be saved over.
      • Files that are not UTF-8 open read-only; Windows line endings and the byte order mark are kept.
      • Autosave (after 5 s by default; 2, 10, 30 s or off in the toolbar).
      • Save as…, Ctrl+S, an "Unsaved changes" mark; settings apply and save at once.
      • Notes that could not be read are no longer replaced by an empty list.
      • Rewritten from scratch; help and history are part of the app instead of its data folder.
